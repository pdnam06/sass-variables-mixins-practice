Thay đổi một lần

Đổi $primary-color trong file biến và biên dịch lại: cả hai nút sẽ được cập nhật cùng lúc.

Chạy npm run build hoặc npm run watch, sau đó mở index.html.

Cấu trúc SCSS

  • abstracts: biến và mixins.
  • base: kích thước, màu chữ của tiêu đề.
  • components: buttons và cards.
  • main.scss: nạp các partial và tạo styles.css.
